# After You Website

A front-end website project for an After You dessert café experience. The project includes a dessert menu, branch information, and a prototype ordering flow.

## Features

- Home page introducing the café
- Dessert menu with search and category filters
- Product pages with available options
- Shopping cart and prototype checkout
- Branch information
- FAQ and contact pages

## Built With

- HTML
- CSS
- JavaScript

## Getting Started

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser, or serve the folder with a local development server.

Keep the `css`, `js`, and `assets` folders alongside `index.html` so the website can load its styles, scripts, and images.

## Usage

Browse the menu, filter desserts by category, and open an item to view its available options. Add items to the cart to explore the prototype ordering experience.

## Project Status

This is a front-end prototype. Checkout is for demonstration purposes and does not process real payments or submit real orders.
